# Pokédex-Tagebuch

Das Pokédex-Tagebuch ist eine JavaScript-Webanwendung, die mit der PokéAPI Pokémon erkundbar macht. Pokémon können nach Name oder ID gesucht, Detailinformationen angezeigt, Favoriten gespeichert und persönliche Notizen verfasst werden. Favoriten und Notizen werden im LocalStorage gespeichert und bleiben dadurch zwischen Sitzungen erhalten.
